适合你这台打印机的制作方法

  1. 先只印一页神牌正面，选择A4、纵向、100%／实际大小，关闭浏览器页眉页脚，不选“适合页面”。用尺量页底校准线，必须为50毫米，再检查神牌宽90、高130毫米。
  2. 正面与背面各用一张薄纸打印，均为单面。你之前220g卡纸翻面进纸失败，这次不要求它再次进打印机。若用220g卡纸，就把它留作夹芯。
  3. 待墨水完全干透，按外侧编号配对。可先留裁切外编号粗裁，再将正反两片背靠背贴在同一片夹芯两侧，最后沿成品边界裁齐；朝向都以中文文字上方为上，勿镜像背面。
  4. 同类隐藏牌的用纸、夹芯、胶层、边缘与背面必须一致。普通记忆一组，候场签另一组；不能留下配对编号、背面笔记或不同方向的裁切痕。神牌背面各不同，不能拿来当隐藏候场堆。
  5. 面板与标记只需单面，贴厚纸后裁下。方形标记保留席位字和形状，颜色只是辅助。用少量均匀的胶，压平后再使用；不把粘好的夹芯重新送进打印机。

容易弄错的五件事

  • 神牌填满立即唤醒，不用再花一个行动。神牌正面交给获记忆者；不另抽一张神明记忆卡。
  • 只在毁座时将神牌翻成废墟。唤醒的神牌保持正面朝上，能力可反复支付骰子发动。
  • 神明记忆不会混入个人牌库。普通记忆只管改骰或燃忆；供奉用标记，不把手牌放到神座。
  • 争夺两骰一起耗尽，没有中途反击；供奉、争夺、毛伊、埃舒、奥贡共用每回合一次供奉变化。
  • 第六更先处理侵蚀，再结束。至少四尊唤醒才比较分数，同分共同胜出。最后新补入但没唤醒的神不计入。
