留住名字，也留下代价

这是一套独立、可结束的三人规则实验。你与两位本地策略对手围坐，用自己的记忆留住神明，也可以改写别人留下的供奉。正式公网 V1.2 不采用这里的改动。

本版用来核对行动闭环与设计假设，尚未证明好玩或平衡。没有好友联机、账号或 AI API。线上入口在本标签页保留进度，刷新可继续；直接打开本地实验原页则刷新重开；“旁观一夜”让本地策略代行你的选择，可随时回到席位。其他人的手牌不公开。

围坐与记忆

固定三人、四尊神、最多六更。每人独立的十张记忆：骨、风、潮、炎、星各两张。各抽四张，首位开始前再抽一张。每回合开始想起一张；牌堆空时，只洗回自己的弃牌。供奉仍属于原主人，真正遗忘的牌永不洗回。

每更三人各行动一次。第一更从你开始，以后每更轮换起始者。此实验没有额外角色传承、心火资源或新神补位。

一回合如何流动

  1. 想起一张记忆（自动完成）。
  2. 可选一次回想、遗赠或燃忆，也可保留记忆跳过。
  3. 选择一次主行动：供奉、改写、呼名、安魂、寻忆或守望。
  4. 手牌超过五张时，逐张放入自己的弃牌，直至五张。交棒给下一人。
主行动付出与结果
供奉把一张相符记忆放入神的空语素槽。个人全场最多四枚供奉。神明记忆可当任一语素。
改写针对别人的已占语素槽，献一张相符记忆，另弃任意一张。对方立即回应：弃相符记忆（或神明记忆）守住；或让出，取回旧供奉至弃牌并得1余音。守住时你的两张牌都进入弃牌。无论成败，均消耗主行动；没有连续反击。
呼名一尊在场神的三语素已填满，且你至少有一枚供奉时，可花主行动唤醒祂。多数者得到5分和专属记忆；三人平分时各得1余音和一张独立专属记忆。没有额外卡牌费用。
安魂仅限侵蚀恰为2的在场神。弃两张，其中至少一张为普通“骨”。先支付费用并消耗主行动。若有其他贡献者，由其中贡献最多的一人回应，同数按安魂者之后的顺序。对方可燃忆留名阻止，或允许安魂。无人贡献或允许后，神退场，所有供奉归还各自弃牌；你得2分与一次性遗赠。不额外摸牌或恢复资源。
寻忆想起两张，回合结束仍需留到最多五张。
守望保留手中的记忆，结束主行动。

把名字凑齐，还需要你开口

三语素填满后，神仍在场，不会在每更末尾自动结算。任意贡献者可在自己的主行动“呼名”：拥有至少两枚供奉的人得5分，专属记忆直接进入其手中。其他贡献者每枚供奉得1余音。呼名者不一定是得到5分的人。

如果三人各有一枚供奉，则众声觉醒：各得1余音，各得到一张属于自己的神明记忆，没有5分奖励。你可以花一回合改写，争取独得祂；也可以现在呼名，让所有人记住祂。两者之间的迟疑，会让神继续承受侵蚀。

呼名后神退场，所有供奉回到各自弃牌。得到的记忆不补发额外行动：呼名者直接进入回合整理，超过五张仍需放下；其他人收到记忆后，到自己的正常时机再行动。记忆可用作万能供奉，或在辅助时机弃掉以发动能力，以后仍可洗回。

填满的神仍能被改写、安魂或侵蚀毁灭。第六更结束时，没来得及呼名的神不会自动给分。离场后不补神。

祂如何留在你的记忆里

神 / 所需语素回想或遗赠效果
毛伊 / 骨、潮、风移动自己一枚供奉至另一尊在场神的相同语素空槽。
贝雅薇 / 炎、星、风移除一尊在场神的一点侵蚀。
火姥神 / 骨、炎、星取回自己弃牌中一张记忆，不能取回本次发动所弃的专属记忆。
查克 / 潮、风、星一尊侵蚀为0或1的神增加一点侵蚀，你想起一张。

安魂所得遗赠使用相同效果，只能使用一次；用尽后安魂的2分保留。没有有效目标时不能发动。所有回想、遗赠、燃忆共用每回合一次的辅助时机。

燃忆与侵蚀

燃忆永久移除一张手牌，留下1伤痕（终局−1分），换取想起两张或为一尊神减一点侵蚀。自己的存续记忆（手牌、牌堆、弃牌、供奉）必须多于六张才能燃忆。被燃掉的专属记忆也不会回来。

每更开始侵蚀以下神各一点：第一更火姥神；第二更毛伊、查克；第三更贝雅薇、火姥神；第四更毛伊、查克；第五更贝雅薇、火姥神；第六更全部在场神。侵蚀到3立即毁座，供奉退回，永不补位。退场的神不再受侵蚀。

天明与余火

第六更所有人行动结束，或每更末尾全部神退场，游戏结束。每更开始侵蚀使最后神退场也立即结束。未填满的供奉没有终局分。天明时没有任何一尊神被唤醒（多数或众声皆可），则共同失败，个人分数只作记录；否则比较“唤醒×5＋安魂×2＋余音－伤痕”，最高者获胜，同分共同获胜。安魂、遗赠或填满却未呼名的神座，都不能替代至少一次唤醒。

安魂之际，燃忆留名

被指定的唯一回应者可以永久燃掉一张手中匹配该神任一语素的记忆，或任意神明记忆，留下1伤痕（−1分），阻止安魂并将侵蚀从2降到1。所有供奉保持原位。存续记忆必须多于六张；没有可燃牌或不愿付出，可以让祂安息。其他玩家没有第二轮回应。

被阻止时，安魂者已经支付的两张牌与主行动不退回，也没有安魂分数或遗赠。无论回应结果如何，都回到安魂者的整理阶段。燃忆留名是即时回应，不占用回应者以后回合的辅助行动，也不增加任何主行动。它留住机会，不会自动唤醒神。

例如：听冬占据两处供奉，你要为祂安魂。听冬可永久失去一张匹配记忆，保留未来呼名得5分的机会；也可以不再付出，让你带走遗赠。若天明前剩余主行动已经不足以补齐空槽再呼名，留名依然合法，但页面会明确提醒这段机会已经无法使用。

M0.4改了什么

沿用M0.3的共同目标与计分，只为安魂加入一次有代价的回应。安魂发起者的默认策略根据公开贡献、公开张数与剩余行动估计被阻止风险；回应策略避免在剩余行动不足时燃忆。这仍是局部判断，不读取其他玩家牌面，不保证最优。同分目标的优先顺序会随每次重新点火轮换，避免每一夜总先争同一尊神；更高评分的行动仍然优先。

让选择进入这一夜的故事

每尊神的结局回顾保留真实供奉、燃忆、争夺、呼名与神明记忆的后续使用。新增完整的安魂尝试、谁付出哪张记忆阻止、谁选择送别，按实际顺序写入，并提供可展开的事件记录和文本下载。不会把留名直接描述为成功救神；祂最终仍可能被遗忘。神明记忆用于后续供奉、改写费用、守护或安魂时，也会记入来源神的故事。每位持有者的第一次用途、第一次回想与最终永久牺牲可追溯；付出改写费用不等于改写已经成功。

验证与局限

10项定向规则检查和180局固定、混合、随机合法行动通过。覆盖先付费用、指定回应者、永久移除与六张底线、返还归属、末更时序、公开信息边界与叙事追溯。180局出现49次回应窗口，其中6次阻止、43次允许；这些混合策略数据用于检查行动闭环，不能证明平衡或真人乐趣。

另检查回应界面的实际脚本渲染、永久遗忘确认取消、实体牌筛选、无牌说明、刷新恢复与不同版本的记录隔离。上述为程序检查，没有新增浏览器视觉或手机真机验收。

  • 本版为三人单机实验，与两位本地策略对手进行，不是好友联机。
  • 临近天明获得的神明记忆可能没有后续用途；不为此增加空转回合。
  • 最后一神可能成为让他人承担牺牲的筹码；尚未证明这个压力足够公平。
  • 不同版本独立保留标签页进度；此候选规则尚未成为正式版。
