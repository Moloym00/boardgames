## 📦 各作品速览

### 1. 《今晚必须有个预言成真》（推荐首选 ⭐）
* **定位**：3～5人 / 15～20分钟 / 黑色幽默 / 心理博弈 / 撞车落空
* **特色**：
  * **机制**：“公开宣告 + 暗扣同牌”，恰好1人前往则神迹应验得分；≥2人前往则“天启拥堵（撞车）”双双被捕落空！
  * **组件**：全套 36 张卡牌（20张基础行动牌 + 6张宫廷异象牌 + 5张司天神职牌 + 5张对局速查牌）。
  * **制作门槛**：仅需 4 张 A4 纸双面打印，横竖 8 刀通贯裁切完成。

### 2. 《劫走黎明》
* **定位**：4～8人 / 20～30分钟 / 蒸汽朋克空战 / 三元克制 / 无阵营单人获胜
* **特色**：
  * **机制**：炮击、钩索、俯冲循环克制；打出指令次轮冷却；三人齐聚全员落空。
  * **组件**：全套指令牌 + 10 幅独立手绘私人委托卡 + 中央空域图。
  * **制作门槛**：A4 纸绝对几何居中，正反翻面通贯 8 刀直出成卡。

### 3. 《真名之火 · 最后的火塘》（火塘守夜 🔥）
* **定位**：3～6人 / 30～45分钟 / 语素拼名 / 半合作共存 / 传火争先
* **特色**：
  * **机制**：骨·风·潮·炎·星五大语素组合真名供奉诸神，濒死抢救安魂留下终局遗赠。
  * **组件**：6 大传承萨满、12 尊古神明牌、12 张初深极夜风暴牌、极夜合诵机制。
  * **双重排版**：提供支持明暗主题切换与内置交互计分器的【沉浸版玩法书】，以及方便桌边随时查阅的【简洁版玩法书】。

## 🖨️ 打印与自制说明 (佳能 G3812 调优)

1. 在浏览器打开对应的 `cards.html` 页面；
2. 按 `Ctrl + P` 调起打印对话框：
   * **纸张**：选择 A4；
   * **缩放**：选择 100%（实际大小）；
   * **边距**：选择“无”或“默认”；
   * **背景图形**：务必勾选【背景图形/颜色】。
3. 打印完成后，用钢尺对齐页面边缘的高精度对齐标尺，美工刀**横拉 4 刀、竖拉 4 刀**，即可切出完整平直矩形卡牌。
